# Anagrammes

Les lettres d’un mot ont été mélangées : remets-les dans l’ordre avant la fin du temps. En pixel art.

*English version: [README.en.md](README.en.md)*

## Commandes

- **Clavier** : tape les lettres du mot, **Retour arrière** pour enlever la dernière.
- **Souris** : clique sur les lettres, ou sur une case pour enlever.
- **Espace** : mélanger encore · **Tab** : un indice · **Échap** : pause.
- **Manette** : gauche et droite pour choisir une lettre, **A** pour la poser, **X** pour enlever, **Y** pour un indice, **RB** pour mélanger.

## Comment ça marche

- 5 mots par niveau. Ils s’allongent tous les deux niveaux, de **4 à 9 lettres**.
- Un **autre mot** qui utilise toutes les lettres compte aussi (NICHE pour CHIEN).
- Un **indice** place la lettre suivante, mais coûte des points ; le temps qui reste en rapporte.
- Le temps fini, la partie s’arrête et le mot s’affiche.

## Données et synchronisation

Le niveau atteint et les records sont enregistrés par NeoDex, sauvegardés et synchronisés entre tes PC si la synchro est activée.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Anagrammes → Installer**.
